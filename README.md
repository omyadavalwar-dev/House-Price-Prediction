House Price Prediction

A beginner-level machine learning project exploring house-price prediction using Python, Pandas, NumPy, and scikit-learn.

Project files

- 'House_Price.ipynb' — Jupyter Notebook containing the project workflow.
- 'HousePricePrediction.cs' — Dataset used by the notebook.
- 'requirements.txt' — Required Python packages.
- '.gitignore' — Files and folders excluded from Git.

Tools and libraries

- Python
- NumPy
- Pandas
- Jupyter Notebook
- scikit-learn

How to run

1. Clone or download this repository.
2. Install the required packages:

   '''bash
   pip install -r requirements.txt
   '''

3. Keep 'HousePricePrediction.csv' in the same folder as 'House_Price.ipynb'.
4. Open the notebook in Jupyter and run the cells.

Project status

The project uses a machine learning regression model and reports an R² score of approximately 0.74 (74%), as measured during the current evaluation.

This is a beginner-level learning project and may be improved in future versions.
